# 03-02 因子评估、模型和回测

## S0：评估时间语义与边界

本子阶段只接受阶段03-01已验证的`CANDIDATE / RESEARCH_ONLY`因子记录及其固定DataVersion；不得把
`DRAFT`、`ACTIVE`或未绑定Artifact证据的因子作为评估输入。首个纵向切片只计算每日横截面IC和RankIC，
不训练模型、不产生快照、不激活因子，也不调用第三方数据源。

每条评估样本必须保存`asOfDate`、`featureAvailableAt`、`forwardReturnStart`和`forwardReturnEnd`。特征时间
必须不晚于冻结的UTC截止时间，收益标签开始日必须严格晚于`asOfDate`；当前日或未来收益、非UTC时间、窗口外
样本、同一股票日在同一截面重复以及常量截面均立即失败。输出按日期稳定排序、固定8位精度并产生
`canonicalContentHash`，继续标记为`RESEARCH_ONLY`。

分层收益按因子平均秩分桶；同值不按输入顺序强行拆分。首版报告最低/最高分层收益、long-short收益和最高分层
相邻截面的成分替换率（`1 - 交集 / 并集`）。截面小于分层数、端点分层为空、重复证券或输入时间不合格时失败，
不得以随机分组、零收益或零换手替代。

因子相关性只在相同`asOfDate + securityId`交集上计算，并按因子 ID 稳定排序；缺少成对观测或常量序列必须失败。
时间稳定性报告固定输出每日 IC 均值、标准差、ICIR和正 IC 比率；单日或零波动时 ICIR 为空，不得伪造数值。

时序切分固定为互不重叠的`train`、`validation`、`test`日期段，禁止随机打乱。样本按`asOfDate`归属分段，且
`forwardReturnEnd`必须不超过所属分段末日；跨越验证或测试边界的标签必须失败，不能让训练标签看到未来。

Walk-forward使用固定交易日日历、训练/验证/测试长度及滚动步长生成多个窗口；每个窗口重复上述边界检查，窗口
不足或日历乱序立即失败。首版只产出带规范Hash的切分数据集，模型训练和参数选择必须在后续步骤中独立实现。

模型注册必须绑定模型代码Hash、参数Hash、DataVersion、FactorSet版本、时序切分Hash和随机种子。成功训练必须
有模型Artifact，失败训练不得发布Artifact；评估报告至少记录成本模型版本与样本外标记，样本内报告不得将模型
状态设置为`ACTIVE`。

首版基线仅实现单因子线性回归`y = intercept + coefficient × factor`，只读取`train`分段，输出截距、系数、
训练行数和规范Hash并保持`RESEARCH_ONLY`。特征常量、模型类型不匹配、DataVersion不一致或训练样本不足时失败；
验证集和测试集不得参与拟合参数。

基线评估只能选择`validation`或`test`分段，输出逐行预测及MAE、MSE、R²，并关联已成功的TrainingRun和成本模型
版本。`train`评估必须拒绝；报告固定标记`outOfSample=true`，但仍保持候选状态，不能绕过后续回测和人工准入。

成本模型首版固定记录佣金、最低佣金、卖出印花税和双边滑点版本。成本后报告单独保存毛收益、平均交易成本和净
收益，并引用来源评估报告与成本模型版本；不得覆盖无成本报告，也不得把成本设置为零来绕过门禁。

回测执行器在信号日之后的执行日才允许成交；停牌、缺少执行价格、买入涨停、卖出跌停和低于最小交易单位时
返回明确拒绝原因并执行数量为零。数量按最小交易单位向下取整，回测拒绝结果仅属于研究输出，不创建订单或交易提案。

最小组合回测将买入与卖出组成往返交易，先执行两边可成交性检查，再汇总有效交易的毛损益；拒绝的往返交易
保留原因但不计入损益。输出`GROSS`和`AFTER_COST`两份摘要，分别记录投入金额、收益、成本、净收益、成交数、
拒绝数和规范Hash。

模型参数和回测报告必须写入内容寻址的不可变Artifact；模型键绑定模型版本和模型规范Hash，回测键绑定运行 ID、
成本后规范Hash，文件SHA-256用于完整性校验。相同内容重复发布必须幂等，键冲突但内容不同必须失败。

读取器必须先验证Artifact引用SHA-256，再解析模型或回测Schema；非法JSON、Schema错误、内容篡改和错误引用均拒绝，
不得使用未校验的本地文件或缓存恢复研究结果。

应用层只开放运行、评估和回测元数据的只读查询接口：`GET /api/v1/runs/{runId}`、
`GET /api/v1/evaluations/{reportId}`和`GET /api/v1/backtests/{runId}`。查询不到返回404；API不得提供因子晋级、
模型激活、交易提案或订单写接口。

## 实施步骤

1. 实现IC、RankIC、分层收益、换手、相关性和稳定性报告。
2. 固化train/validation/test和Walk-forward时序切分，禁止随机打乱时间。
3. 建立ModelDefinition、ModelVersion、TrainingRun和EvaluationReport。
4. 首版使用简单线性/树模型作为基线，再接Qlib模型；复杂模型不得早于基线。
5. 回测纳入停牌、涨跌停、最小交易单位、成本、滑点和信号可成交时间。
6. 所有结果保存DataVersion、UniverseVersion、代码Hash、参数、随机种子和Artifact Hash。

## 测试

- 标签和特征时间错位会被泄漏检测拒绝。
- 无成本与成本后结果分开。
- 相同输入可复现；改变成本模型产生新评估版本。
- 过拟合、样本外失败和高换手不能晋升ACTIVE。
- IC/RankIC只使用严格后续收益；当前日标签、未来可见特征、常量截面和重复股票必须被拒绝。
- 分层收益对同值稳定，最高分层换手率可复算；空端点分层、截面小于分层数和伪造的零换手必须失败。
- 相关性只能使用同日同证券交集；相关性常量序列、配对不足或未来可见值必须失败。稳定性指标需可由每日 IC 报告重算。
- 时序切分必须稳定、三段均有样本且无重叠；跨边界收益标签、窗口外样本和逆序日期必须失败。
- Walk-forward窗口由交易日日历确定且可重复，滚动步长、窗口Hash和每个窗口的标签边界必须可审计。
- 模型训练运行的DataVersion与时序切分Hash必须匹配；成功/失败Artifact规则和样本外激活门禁必须测试。
- 线性基线只能使用train数据，参数在相同输入下可复现；常量特征、样本不足和非线性算法必须拒绝。
- 基线预测只能读取validation/test；训练运行未成功、数据版本不一致或请求train评估必须失败，MAE/MSE/R²需可复算。
- 交易成本测试必须覆盖最低佣金、买卖方向、印花税、滑点和成本后结果；毛收益与成本后报告必须独立且可复算。
- 回测执行测试必须覆盖信号延迟、停牌、涨跌停、最小交易单位和缺少价格；拒绝原因与零成交数量必须可审计。
- 模型与回测Artifact测试必须覆盖内容寻址、父版本绑定、重复发布幂等和篡改/冲突拒绝。
- Artifact读取测试必须覆盖SHA-256不匹配、非法JSON和Schema错误；恢复只能使用通过完整性校验的对象。
- 元数据API必须覆盖已登记记录查询、未知ID的404和写请求405；OpenAPI中不得出现模型激活或交易写接口。
