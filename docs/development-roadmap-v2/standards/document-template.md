# 阶段与实现文档模板

## 阶段总设计必须包含

- 目标、价值和非目标。
- 前置阶段及输入契约。
- 开发边界和禁止事项。
- 顺序子文档与依赖。
- 服务/数据库/事件所有权。
- 失败和降级策略。
- 测试矩阵和验收门禁。

## 子开发文档必须包含

1. 目标与完成定义。
2. 前置条件。
3. 文件和目录清单。
4. 按顺序的实现步骤。
5. 关键代码或Schema骨架及解释。
6. 错误、幂等、安全和观测要求。
7. 本步骤测试案例和命令。
8. 禁止实现的范围。
9. 完成检查与下一文档入口。

## 代码骨架原则

代码用于明确接口、依赖方向和关键业务约束，不作为可直接复制的完整实现。真实代码必须补齐类型、异常、日志、超时、测试和配置校验。
